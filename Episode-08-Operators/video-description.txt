Operators let your program calculate. In this lesson, we try every C# arithmetic operator in a playground, learn assignment operators and operator precedence, and then build a real menu-driven calculator in VS Code. Everything is a real recording: real code, real output, two real crashes, and the fixes.

This is episode 8 of the Complete C# Course for Beginners on ITHubCoding. It continues from Episode 7 (Constants and Type Conversion). Earlier episodes are in the course playlist.

WHAT YOU WILL LEARN
• The arithmetic operators: + - * / and % (remainder, not percent)
• Why 17 / 5 is 3.4 with decimal but 3 with int (integer division)
• Assignment operators: = replaces a value, += and -= update it
• Operator precedence: 2 + 3 * 4 is 14, and (2 + 3) * 4 is 20
• Building a calculator: decimal.TryParse for safe input and a switch for the menu
• Handling invalid input and unknown operations without crashing
• Division by zero: a real DivideByZeroException, and how to prevent it
• Testing every operation, and fixing a second bug that testing found
• Real compiler errors explained: CS0163 (missing break), CS0165 (unassigned variable), CS0029 (= instead of ==)

THE APP
CSharpCalculator reads two numbers safely with decimal.TryParse, shows a menu of operations (+ - * / %), calculates the result with a switch, and prints the calculation, for example 12.5 * 4 = 50.0. Text input, unknown operations, and division or remainder by zero are rejected with a helpful message instead of a crash.
