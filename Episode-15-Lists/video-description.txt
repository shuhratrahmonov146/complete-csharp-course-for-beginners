Your shopping list changes every day: you add items, buy them, and cross them off. An array can't do that, because its length is fixed. In this lesson, you learn C# lists: a collection that grows and shrinks. We build a real Shopping List Manager in VS Code that adds, shows, and removes items, and handles an empty list and missing items with clear messages instead of crashing.

This is episode 15 of the Complete C# Course for Beginners on ITHubCoding. It continues from episode 14, where we stored many values in one array: https://www.youtube.com/watch?v=rKOcMN6M4uQ
Earlier episodes are in the course playlist.

WHAT YOU WILL LEARN
• Arrays vs lists: a fixed length vs a collection that grows and shrinks
• Creating a list of strings: List of string, items = new List of string(), and the shorter new()
• Adding items with Add (always at the end)
• Reading and updating items by index (the first index is 0), and checking an index safely
• Remove: it returns true when the item was removed and false when it was not found
• Remove vs RemoveAt (by value vs by index)
• Count (lists) vs Length (arrays), and Contains (true or false)
• Looping through every item with foreach
• Handling an empty list and a missing item with clear messages

THE PROGRAM
ShoppingListManager is a menu app: 1 Show list, 2 Add an item, 3 Remove an item, 4 Exit. It rejects empty names and duplicates, says "Nothing to remove. The list is empty." on an empty list, and "Pizza is not on the list." when you remove an item that isn't there.

YOUR CHALLENGE
Add option 4, Check an item, using Contains, and move Exit to option 5. Test it with an item that is on the list and one that is not. Details are in the pinned comment.
