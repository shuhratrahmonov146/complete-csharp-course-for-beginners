In this lesson, you will install the .NET SDK, check that it works, choose an editor (Visual Studio or VS Code), and run your first C# project with dotnet run. By the end, your own computer will print "Hello, World!" and you will be ready for the next lesson.

This is episode 2 of the Complete C# Course for Beginners on ITHubCoding. It continues from Video 1, "Your First C# Program — From Zero to Hello World".

WHAT YOU WILL LEARN
• The difference between C#, the .NET SDK, the .NET runtime, and an editor/IDE
• How to choose and install the right .NET SDK (.NET 10 LTS) on Windows, macOS, or Linux
• How to verify your installation: dotnet --version, dotnet --list-sdks, dotnet --list-runtimes
• Visual Studio vs. Visual Studio Code: what each one needs
• How to run a project with dotnet run, and create one with dotnet new console
• How to fix 5 common problems: "dotnet" not recognized, wrong folder, no project found, SDK vs. target framework mismatch, editor can't find the SDK
