What is a variable in C#? In this lesson, we build a real Student Profile App in VS Code and learn how to store information, change it, and use it again. Everything is a real recording, with real builds, real output, and real compiler errors.

This is episode 5 of the Complete C# Course for Beginners on ITHubCoding. It continues from Episode 4 (Console Input and Output). Earlier episodes are in the course playlist.

WHAT YOU WILL LEARN
• What a variable is: a name, a type, and a value
• Declaring and initializing: string studentName = "Alex";
• string (text) vs. int (whole numbers), and why C# checks types
• The difference between a variable's name and its value
• Changing a value (reassignment) without repeating the type
• Using variables with Console.ReadLine and string interpolation
• Common mistakes with real compiler errors: CS0128, CS0029, CS0103, CS0841
• Tracking progress with completedLessons = completedLessons + 1
• Naming habits: descriptive camelCase names, and the rules the compiler enforces
