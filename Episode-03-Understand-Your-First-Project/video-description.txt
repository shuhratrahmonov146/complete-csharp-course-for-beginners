In this lesson, we open the C# project from the last two videos and find out what is really happening behind the scenes. You will learn what Program.cs and the .csproj file do, what "building" means, how dotnet build and dotnet run are different, and how to read and fix a real compiler error.

This is episode 3 of the Complete C# Course for Beginners on ITHubCoding. It continues from Episode 1 ("Your First C# Program — From Zero to Hello World") and Episode 2 ("Install .NET and Set Up Your C# Development Environment"). You can find them in the course playlist.

WHAT YOU WILL LEARN
• What a project is, and the three kinds of files in it
• Every part of Console.WriteLine("Hello, World!");
• Top-level statements, and why you don't have to write a Main method yourself
• The .csproj settings: OutputType, TargetFramework, ImplicitUsings, Nullable
• The difference between the target framework and the SDK version
• What dotnet build does, and how to read its output
• dotnet build vs. dotnet run
• How to predict a program's output before you run it
• How to read and fix a real compiler error (CS1002: ; expected)
• What the bin and obj folders are, and why you shouldn't edit them
