Some employees get a fixed monthly salary. Others are paid for every hour they work. How can one line of code calculate both salaries correctly? In this lesson, you learn C# polymorphism: one method call, different behaviors. We build a real Employee Payroll System in VS Code, step by step, with virtual, override, and one List of Employee.

This is episode 21 of the Complete C# Course for Beginners on ITHubCoding. It continues from episode 20, C# Inheritance: https://youtu.be/AAy9uaDp1Pc
The full course is in the playlist.

WHAT YOU WILL LEARN
• What polymorphism means: poly = many, morph = forms
• Why a separate list and a separate loop for every employee type is hard to maintain
• A base class with a virtual method: public virtual decimal CalculateSalary()
• Overriding it in derived classes: public override decimal CalculateSalary()
• Classes in a Models folder, with a namespace and a using directive
• One List of Employee that holds full-time and part-time employees
• Runtime polymorphism: the same call runs the version of the real object
• A base-class variable that refers to a derived object
• Common mistakes: forgetting virtual (error CS0506), forgetting override (warning CS0114), override without a matching method (error CS0115), overriding vs overloading, and the wrong list type (error CS1503)

THE PROGRAM
EmployeePayrollSystem has an Employee base class (EmployeeId, Name, a virtual CalculateSalary, and ShowInfo) and two derived classes: FullTimeEmployee (the monthly salary) and PartTimeEmployee (hours worked × hourly rate). Its real output:
Ali (ID 101)
Salary: 3000

Sara (ID 102)
Salary: 1200

Total payroll: 4200

YOUR CHALLENGE
Create a base class Shape with a virtual CalculateArea() method. Then create Circle and Rectangle, and give each one its own CalculateArea(). Put both objects into a List of Shape, and call CalculateArea() in a foreach loop. Details are in the pinned comment.
