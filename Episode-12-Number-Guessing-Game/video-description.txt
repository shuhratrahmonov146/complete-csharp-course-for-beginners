Can your C# program think of a secret number and challenge you to find it? In this lesson, we build a real number guessing game from scratch in VS Code. The computer picks a random number from 1 to 100, the player guesses, and the game answers "Too low!", "Too high!" or "Correct!" until the number is found. Everything is real: real code, real VS Code recordings, and real games against a real random number.

This is episode 12 of the Complete C# Course for Beginners on ITHubCoding. It continues from episode 11: C# Loops Explained — for, while, and do-while with a Real Project. Earlier episodes are in the course playlist.

WHAT YOU WILL LEARN
• Random numbers with the Random class, and why random.Next(1, 101) gives 1 to 100 (the second number is never included)
• Reading the player's guess with Console.ReadLine
• Validating input with int.TryParse, and rejecting numbers outside 1 to 100
• Comparing with if, else if and else: too low, too high, correct
• Repeating the game with a while loop, and ending it with a bool (isCorrect)
• Counting only valid attempts
• 5 common mistakes: no loop, the wrong random range, comparing before validating, counting invalid guesses, and a loop that never ends

THE GAME
NumberGuessingGame picks a secret number from 1 to 100. Text like hello is rejected ("Please enter a whole number."), and so are numbers like 0, -5 and 101 ("Please enter a number from 1 to 100."). Invalid entries are not counted as attempts. In the final game of the video, the secret was 72, found in 7 valid attempts.

YOUR CHALLENGE (optional)
Limit the game to ten valid guesses. If the player can't find the number, show a game over message and reveal the secret number. Details are in the pinned comment.
