In this lesson, we build our first interactive C# program: a console app that asks questions, reads real keyboard input, checks it, and prints a neat profile. Every demo is a real recording in VS Code, with real builds, real output, a real crash, and real fixes.

This is episode 4 of the Complete C# Course for Beginners on ITHubCoding. It continues from Episodes 1–3 (Hello World, .NET setup, project / build / run). You can find them in the course playlist.

WHAT YOU WILL LEARN
• Console.WriteLine vs. Console.Write, and why Write is perfect for questions
• Reading input with Console.ReadLine, and why it can return null (warning CS8600)
• Handling null with ?? ""
• Storing answers in variables and reusing them with string interpolation $"…{name}…"
• Why "25" + 1 prints 251, the difference between text and numbers
• int.Parse vs. int.TryParse: a real crash, and the safe fix
• Testing real scenarios (empty name, invalid age, empty goal) and fixing what breaks

THE FINAL PROGRAM
PersonalProfileApp asks for your name, age, and programming goal, validates the age with int.TryParse, handles empty answers with Trim() and defaults, and prints a formatted profile.
