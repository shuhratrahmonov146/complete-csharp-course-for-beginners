Creating an object and then setting every property on its own line gets repetitive, and it's easy to forget a line. A constructor fixes that: it initializes an object the moment it's created. In this lesson, you build a Student class in VS Code, write constructors with and without parameters, create several objects in one line each, and see real compiler errors for the most common constructor mistakes.

This is episode 18 of the Complete C# Course for Beginners on ITHubCoding. It continues from episode 17, C# Classes and Objects: https://www.youtube.com/watch?v=iMhTZLJr040
The full course is in the playlist.

WHAT YOU WILL LEARN
• Why setting every property by hand is repetitive and error-prone
• Constructor syntax: the same name as the class, and no return type (not even void)
• When a constructor runs: every time new creates an object
• Constructor parameters: how new Student("Ali", 16) passes arguments, in order
• Creating several objects with the same constructor and different values
• The hidden parameterless constructor, and why new Student() stops compiling (CS7036) once you write your own constructor
• Constructor overloading: several constructors with different parameter lists
• Common mistakes with real compiler errors: void before the name (CS0542), arguments in the wrong order (CS1503), a misspelled name (CS1520), a wrong number of arguments (CS1729)

THE PROGRAM
ConstructorBasics has a Student class with Name, Age and Grade and three constructors: Student(), Student(string name, int age) and Student(string name, int age, int grade). Program.cs creates three students, each with a different constructor, and each one introduces itself: "Hi, I'm Ali. I'm 16 and I'm in grade 11."

YOUR CHALLENGE
