Method overloading and method overriding sound similar, but they work very differently. In this beginner-friendly C# lesson, you learn the difference step by step, and build a real Employee Management System in VS Code that uses both.

This is episode 22 of the Complete C# Course for Beginners on ITHubCoding. It continues from episode 21, C# Polymorphism: https://www.youtube.com/watch?v=Bkaq-nusiJM
The full course is in the playlist.

WHAT YOU WILL LEARN
• Method overloading: the same method name with different parameter lists
• Valid overloads: a different number of parameters, different types, or a different order of types
• Parameters vs arguments
• How the compiler picks an overload from the arguments, at compile time (error CS1501 when nothing matches)
• Method overriding: a derived class gives its own implementation of an inherited virtual or abstract method
• virtual in the base class, override in the derived class
• How the real object picks the override while the program runs (runtime polymorphism)
• Both together: a List of Employee and one foreach loop
• A side-by-side comparison of overloading and overriding
• Common mistakes: changing only the return type (CS0111), forgetting virtual (CS0506), override with a different parameter list (CS0115), and forgetting override (warning CS0114)

THE PROGRAM
EmployeeManagementSystem has an Employee base class with four overloaded DisplayInformation methods and a virtual CalculateSalary method. FullTimeEmployee (a monthly salary) and PartTimeEmployee (hours worked times the hourly rate) override CalculateSalary. Its real output:
Name: Ali, ID: 101
Salary: 4500

Name: Maria, ID: 102
Salary: 1760

Name: Daniel, ID: 103
Salary: 3800

YOUR CHALLENGE
1. Overloading: create a Calculator class with three Add methods: two integers, three integers, and two decimal values.
2. Overriding: create a Notification base class with a virtual Send method, then EmailNotification and SmsNotification classes that override it. Call Send in a loop. Details are in the pinned comment.
