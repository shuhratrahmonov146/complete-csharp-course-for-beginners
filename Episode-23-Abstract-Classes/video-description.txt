Credit cards and PayPal are both payment methods, but each one processes a payment in its own way. How do you make every payment type follow the same structure, and make sure no class forgets its own ProcessPayment method? In this lesson, you learn C# abstract classes and abstract methods, step by step, by building a real (simulated) payment processing system in VS Code.

This is episode 23 of the Complete C# Course for Beginners on ITHubCoding. It continues from episode 22, Method Overloading vs Method Overriding, and builds on episode 21, C# Polymorphism: https://www.youtube.com/watch?v=Bkaq-nusiJM
The full course is in the playlist.

WHAT YOU WILL LEARN
• Why an ordinary base class with an empty method is not enough
• What an abstract class is: a general blueprint you cannot create objects from
• What an abstract method is: no body, and every non-abstract derived class must implement it
• Why new PaymentMethod(100m) fails with error CS0144
• How CreditCardPayment and PayPalPayment implement ProcessPayment() with override (error CS0534 if you forget)
• Abstract variable type, concrete object: PaymentMethod payment = new CreditCardPayment(100m);
• Shared code in an abstract class: properties, a protected constructor, and ordinary methods
• Polymorphism with a List of PaymentMethod and a foreach loop
• Abstract class vs ordinary class, and when to use an abstract class
• Common mistakes: CS0144, CS0500, CS0534, and the missing override keyword (warning CS0114)

THE PROGRAM
PaymentProcessingSystem has an abstract PaymentMethod class (PaymentAmount, a protected constructor, DisplayPaymentInformation, and the abstract ProcessPayment), and two derived classes in a Models folder: CreditCardPayment and PayPalPayment. It is a local simulation: no real payments, no card data. Its real output:
Amount: 120.50 USD
Checking the credit card...
Credit card payment approved.

Amount: 45.99 USD
Connecting to PayPal...
PayPal payment completed.

YOUR CHALLENGE
Create an abstract class called Shape. Add an abstract method named CalculateArea(). Then create two derived classes: Circle and Rectangle. Implement CalculateArea() differently in each class. Finally, create a List of Shape and calculate the area of every shape using a foreach loop. Details are in the pinned comment.
