What if a program should keep showing its menu until the user chooses Exit? Copying the same code again and again would be messy. Instead, C# gives us loops. In this lesson, we learn the for, while, and do-while loops step by step, with animations that follow the real code, and then upgrade our Student Menu app so it repeats until the user chooses Exit. Everything is real: real code, real VS Code recordings, real output, and real bugs found by testing.

This is episode 11 of the Complete C# Course for Beginners on ITHubCoding. It continues from episode 10, where we built the Student Menu with a switch. Earlier episodes are in the course playlist.

WHAT YOU WILL LEARN
• What a loop is, and why it beats copy and paste
• The for loop: start, check, body, update
• The while loop: it checks its condition first, so its body may never run
• The do-while loop: its body runs at least once, and it ends with a semicolon
• for vs while vs do-while: common uses, not strict rules
• How an infinite loop happens, and how to prevent it
• A while loop around a switch: a menu that repeats until Exit
• A for loop that counts to a number the user chooses, with int.TryParse validation
• Common mistakes: forgetting the update, a condition that never becomes false, off-by-one, the missing semicolon (error CS1002), and unvalidated input

THE APP
StudentMenu (from episode 10) now runs inside a while loop: 1. Learn about C#, 2. View course information, 3. Practice counting, 4. Check a passing score, 5. Exit. Option 3 counts from 1 to your number with a for loop: 5 prints 1, 2, 3, 4, 5. Text like abc, zero, negative numbers and numbers over 100 are rejected. Option 5 sets running to false, and the loop ends. If the input ends without choosing Exit, the program treats it as Exit, so it can never get stuck in an endless menu.
